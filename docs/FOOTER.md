# 文末片段（关于我）

X 文章不支持富文本样式，但可以用它支持的块类型搭一个干净的结尾。

## 用法

默认读取 `~/.config/xpub/footer.md`，文件不存在就不追加。

```bash
xpub 文章.md                      # 自动追加（若配置文件存在）
xpub 文章.md --no-footer          # 不追加
xpub 文章.md --footer 自定义.md    # 用别的文件
```

## 推荐写法

```markdown
· · ·

## 关于我

一个人在做海外小站。这个系列按「选词→建站→收款→流量→转化→风控」来写，主页置顶有目录。

方法来自社群分享、公开资料与我的实践。

SEO 方法论出处：「某某」社群。
```

## 为什么这么排

| 元素 | 作用 |
|---|---|
| `· · ·` | 视觉断点，告诉读者正文结束 |
| `## 关于我` | X 里是真二级标题，会进文章目录（右侧导航） |
| 三段短句 | 每段一行，手机阅读刚好 |
| 不写 `@自己` | 文章下方本来就有作者卡片和 bio，重复会显得啰嗦 |

## 注意

- 文末片段里的图片同样会被上传
- 片段里的 `##` 标题会进入文章目录，别写太多
- 发布时可另配一句「金句」作为帖子正文（X 允许 256 加权字符，中文约 120 汉字）
