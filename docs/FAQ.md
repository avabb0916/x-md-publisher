# FAQ

**Q：这算不算违反 X 的条款？**
它使用的是你自己账号的网页端接口，等价于你在浏览器里操作。请自行判断并遵守 X 的服务条款。本项目不提供绕过限制、批量养号等能力。

**Q：一定要 Chrome 吗？**
目前是这样（走 CDP）。Edge/Chromium 理论上可用，把 `XPUB_CHROME` 指向可执行文件即可，未测试。

**Q：能跑在服务器上吗？**
需要一个能持久化 profile 的环境，并且要手动完成一次登录。服务器上没有图形界面时，可以先用有界面的机器登录，再把 profile 目录拷过去。

**Q：为什么我的图片没出现？**
1. 检查 md 里的路径是否相对 md 文件可解析
2. 用 `--verbose` 看上传是否成功
3. 看返回的 `savedMedia` 是否等于图片数

**Q：为什么正文是空的（savedBlocks=0）？**
最可能是块类型不被支持（例如 `###` 直接写、或保留了 inline style）。xpub 已做降级，但仍建议正文只用 `##`。

**Q：能更新已发布的文章吗？**
可以，`--article <id>` 对已发布的文章 ID 也适用（会改动线上内容，谨慎）。

**Q：草稿在哪看？**
X → 文章 → 草稿。或直接打开输出里的 `draftUrl`。
